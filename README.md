# 📚 Студенттік Оқыту Платформасы

Бұл сайт студенттердің өндіктеме процесін басқару, материалдарды ортақтастыру және жоспарлау үшін арналған.

## 🎯 Функциялары

✅ **Студенттік профиль** - Өз номеріңіз арқылы тіркеліңіз  
📚 **Материалдар** - Админ PDF файлдарды жүктей алады  
🎬 **Нұсқа талдаулары** - YouTube видеолары арқылы үш бөлім:
  - 24 сағаттық нұсқа
  - Геометрия
  - Математика  
📅 **Жоспарлау** - Календарь арқылы күндік жоспарлау  
✅ **Бүгінгі тапсырмалар** - Галочка (✓) арқылы орындалды деп белгілеу  
🛠️ **Админ панелі** - Материал және нұсқалар қосу  

## 📋 Техникалық құрылымы

### Backend:
- **Node.js** + Express.js
- **PostgreSQL** деректер базасы
- **JWT** аутентификациясы
- **Multer** файлдарды жүктеу үшін

### Frontend:
- **React 18**
- **React Router** навигация үшін
- **Axios** API сұрауы үшін
- **React Calendar** календарь компоненті

## 🚀 Орну және бастапқы қосу

### 1. PostgreSQL деректер базасын орнату

```bash
# Деректер базасы құру
createdb student_platform

# init.sql скриптін орындау
psql -U postgres -d student_platform -f init.sql
```

### 2. Backend орнату

```bash
# Бәйле болу
npm install

# .env файлын құру
cp .env.example .env

# .env файлды өндеу (қажет болса)
# DB_USER, DB_PASSWORD және т.б. оңдаңыз

# Сервер бастау
npm start
# немесе әзірлеу режімінде:
npm run dev
```

### 3. Frontend орнату

```bash
# React құрылымын құру (Vite немесе Create React App)
npx create-react-app student-frontend
cd student-frontend

# Ынамдарымызды орнату
npm install axios react-router-dom react-calendar react-icons

# Компоненттерді (Login.jsx, Dashboard.jsx және т.б.) скопиялаңыз
# src/pages және src/components папкаларына

# Frontend бастау
npm start
```

## 🔑 Бірінші кіру

**Админ аккаунты:**
- Студент номері: `admin`
- Пароль: (init.sql-де белгіленген)

**Жаңа студент тіркеу:**
1. Тіркеу бөлік-тің бетіне өтіңіз
2. Студент номері (2024001 сияқты цифрлар)
3. Пароль құрыңыз
4. Атыңызды енгізіңіз

## 📚 API Endpoints

### Аутентификация
- `POST /api/auth/register` - Студент тіркеу
- `POST /api/auth/login` - Кіру

### Материалдар (JWT токен қажет)
- `GET /api/materials` - Барлық материалдарын сұрау
- `POST /api/materials` - Материал қосу (админ)

### Нұсқалар
- `GET /api/examinations` - Нұсқаларын сұрау
- `POST /api/examinations` - Нұсқа қосу (админ)

### Жоспарлар
- `GET /api/plans/:date` - Күнге арналған жоспарлар
- `POST /api/plans` - Жоспар қосу
- `PATCH /api/plans/:id` - Жоспарды өндеу

### Бүгінгі тапсырмалар
- `GET /api/daily-tasks` - Бүгінгі тапсырмалар
- `POST /api/daily-tasks` - Тапсырма қосу
- `PATCH /api/daily-tasks/:id` - Тапсырманы өндеу

### Профиль
- `GET /api/profile` - Студенттің профилі

## 🛠️ Материалдар қосу (Админ)

1. Админ аккаунты арқылы кіріңіз
2. "🛠️ Админ панелі" үтсе жөңтіңіз
3. "📚 Материалдар қосу" бөлегінде:
   - Атауын енгізіңіз
   - PDF немесе DOC файлын таңдаңыз
   - "✓ Материалды қосу" түймеп басыңыз

## 🎬 YouTube нұсқалары қосу (Админ)

1. Админ аккаунты арқылы кіріңіз
2. "🎬 Нұсқалар қосу" бөлегінде:
   - Атауын енгізіңіз
   - Бөлімді таңдаңыз (24 сағат / Геометрия / Математика)
   - YouTube видеосының URL-ін енгізіңіз
   - "✓ Нұсқа қосу" түймеп басыңыз
3. Видеоның афишасы автоматты түрде жүктеледі

## 📅 Жоспарлау қалай істейді

1. "📅 Жоспар" бөлегіне өтіңіз
2. Календарьте күнді таңдаңыз
3. Сол жақта:
   - Тапсырманың атын енгізіңіз
   - Уақытты белгілеңіз
   - "+ Қосу" түймеп басыңыз
4. Тапсырма сол күндің жоспарына қосылады

## ✅ Бүгінгі тапсырмалар

1. "✅ Бүгінгі тапсырмалар" бөлегіне өтіңіз
2. Бүгінгі күні жоспарлар көрініп тұрады
3. Әрбір тапсырманы:
   - ☑️ бағалаңыз - орындалды деп белгілеңіз
   - ✕ басыңыз - тапсырманы өндеңіз

## 🌐 Deployment (Railway)

```bash
# Railway-ға конфигурация
# Procfile құру
echo "web: npm start" > Procfile

# Railway CLI орнату және пайдалану
npm i -g railway
railway login
railway init
railway up
```

## 📞 Проблемалар шешу

**"Деректер базасына байланыса алмадым"**
- PostgreSQL істеп жатқанын проверкалаңыз
- .env файлындағы DB_USER, DB_PASSWORD параметрлерін тексеңіз

**"Админ аккаунты жұмыс істемейді"**
- init.sql-нің толық орындалғанын тексеңіз
- `SELECT * FROM students;` командасын орындаңыз

**"YouTube видеолары көрініп тұрмайды"**
- YouTube URL-інің дұрыс форматта екенін тексеңіз
- `https://www.youtube.com/watch?v=VIDEO_ID` немесе `https://youtu.be/VIDEO_ID`
